# V20 ohne Microsoft-Anmeldung

1. Ersetze in GitHub die bisherigen V19-Dateien durch die Dateien aus diesem Ordner.
2. Warte auf die Aktualisierung von GitHub Pages.
3. Installiere die OneDrive-App auf Android und melde dich dort mit deinem Firmenkonto an.
4. Öffne die Lagerverwaltung in aktuellem Chrome oder Edge.
5. Öffne **Dateisynchronisierung**.
6. Tippe auf **Gemeinsame Datei auswählen**.
7. Wähle im System-Dateidialog OneDrive und dort `lager.db`.
8. Vor jedem Gerätewechsel synchronisieren; auf dem neuen Gerät zuerst den Dateistand laden.

Keine Client-ID, keine Entra-App und keine Anmeldung innerhalb der Lagerverwaltung.

Falls die direkte Verknüpfung nicht funktioniert, nutze **SQLite-Datei exportieren/importieren**.
