# Lagerverwaltung Lovrencic V51

## Sofortsuche im Lagerbestand

Das Suchfeld `search` filtert den Lagerbestand jetzt automatisch während der Eingabe.

- Start bereits nach dem ersten Zeichen
- Aktualisierung bei jeder weiteren Eingabe
- funktioniert auf PC und Smartphone
- kurze Verzögerung von 160 ms
- leeres Suchfeld zeigt wieder alle Artikel

Die Materialanforderungsvorlage wurde nicht verändert.
