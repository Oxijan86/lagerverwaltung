# Erste Schritte

Die Lagerverwaltung startet nach der Erstinstallation mit einem Einrichtungsassistenten.

## Ersteinrichtung

- Administratorpasswort mit mindestens 8 Zeichen vergeben.
- Namen des Technikers eingeben.
- Datumsformat auswählen.
- Einrichtung abschließen.

Lagerorte und Maschinen müssen bei der Ersteinrichtung nicht angelegt werden. Sie können später unter **Stammdaten** ergänzt werden.

## Vollständige Smartphone-Einrichtung ab V70

1. **Neue Datenbank erstellen** antippen.
2. Unterstützt der Browser eine Ordnerauswahl, lokalen oder Cloud-Ordner ausdrücklich auswählen. Falls nicht, **Lagerdatenbank auf diesem Gerät erstellen** antippen.
3. Techniker und Datumsformat auswählen.
4. Passwort vergeben und bestätigen.
5. **Lagerverwaltung starten** antippen.
6. Bei Browser-Speicherung öffnet sich Dateisynchronisierung. Mit **lager.db herunterladen** kann die fertig eingerichtete Datenbank als Datei gespeichert werden.

Die Browser-Datenbank bleibt auf diesem Gerät gespeichert. Eine heruntergeladene Datei ist eine Kopie; sie ist nicht automatisch synchronisiert. OneDrive oder Google Drive müssen einen vom Browser tatsächlich nutzbaren synchronisierten Ordner anbieten. Eine Dateiauswahl allein erteilt keine dauerhafte Ordner-Schreibberechtigung. Eine vorhandene lager.db kann bereits auf der ersten Seite über **Vorhandene Datenbank öffnen** eingelesen werden.
