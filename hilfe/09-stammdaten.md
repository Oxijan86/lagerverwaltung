# Stammdaten

## Lagerorte
Lagerorte werden zentral unter Stammdaten angelegt und benötigen eine gültige Administrator-Sitzung. In der Materialanlage können vorhandene Lagerorte ohne Passwort zugeordnet werden; das Erstellen eines neuen zentralen Lagerorts erfordert eine gültige Administrator-Sitzung. Ähnliche vorhandene Namen werden vorher vorgeschlagen.

## Maschinen und alternative Bezeichnungen
Eine Maschine besitzt einen Hauptnamen und kann beliebig viele alternative Ticket-Bezeichnungen erhalten.

- **Alternative Bezeichnung zuordnen:** z. B. `Compas 4` → `Compas 4.0`.
- **Trennen:** eine falsche Alias-Zuordnung kann jederzeit wieder entfernt werden.
- **Maschinen zusammenführen:** zwei bereits getrennt angelegte Maschinen können zu einer Hauptmaschine zusammengeführt werden. Der frühere Name bleibt als Alias erhalten.
- **Zusammenführung rückgängig:** die vorherige Maschine wird wiederhergestellt und ihre Ersatzteil-Zuordnungen werden soweit möglich auf den Stand vor der Zusammenführung zurückgesetzt.

## Mehrfachzuordnung von Ersatzteilen
Ein Artikel kann mehreren Maschinen gleichzeitig zugeordnet werden. Diese Zuordnung ist beim neuen Material sowie in der vollständigen Artikelliste bearbeitbar.
